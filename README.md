# Ciência Delas

Projeto educacional desenvolvido com HTML e CSS, destacando mulheres brasileiras e suas contribuições para a sociedade.

## Sobre o projeto

O site apresenta informações sobre Rita Lee, Zilda Arns e Giovanna Waksman, com seções de navegação, imagens e conteúdos biográficos.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Navegação entre seções
- Apresentação de biografias
- Organização de textos e imagens
- Estilização personalizada com CSS

## Acesse o projeto

[Visualizar site](https://mariaclaratrindade12f-cmyk.github.io/ci-ncia-delas/)

## Objetivo

Desenvolver habilidades em estruturação de páginas web, estilização e organização de conteúdo digital.
